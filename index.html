开箱与首次设置

从按下电源键那一刻，到一台"完全属于你"的 Mac

开箱检查清单

  • 核对配件：MacBook 本体、USB-C 充电线（编织线）、电源适配器（部分型号为双口）
  • 验证真伪：在 Apple 官网「检查保障状态」页面输入包装盒上的序列号，确认激活状态与保修期（checkcoverage.apple.com）
  • 首次充电：锂电池出厂即带电，无需"充满 12 小时"——那是镍氢电池时代的都市传说

首次开机设置助理（Setup Assistant）流程

  1. 长按电源键（Touch ID 键）直到出现 Apple 标志，按提示选择国家/地区、语言、键盘布局（简体中文用户保持默认即可）
  2. 连接 Wi-Fi —— macOS 激活必须联网，建议连 5GHz 频段
  3. 数据迁移抉择点：系统会问"是否从其他设备传输数据"。Windows 用户选「从 Windows PC」（详见下方），或先选「暂时不传输」稍后用迁移助理补搬
  4. 登录 Apple 账户（即 Apple ID）。没有就现场注册一个——它是 iCloud、App Store、查找、连续互通的总钥匙。强烈建议开启双重认证
  5. 设置 触控 ID（指纹）与登录密码。密码是管理员密码，请务必记牢
  6. 同意条款 → 选择外观（浅色 / 深色 / 自动）→ 完成，进入桌面
Windows 你熟悉的
  • 微软账户可选"脱机账户"
  • 迁移靠 U 盘 / 移动硬盘手动拷
  • 首次更新驱动一堆弹窗
macOS 现在这样
  • Apple 账户深度绑定，但不登录也能用（部分功能受限）
  • 迁移助理一键从 PC 搬家（邮件/联系人/日历/文件/书签）
  • 无驱动弹窗，系统自带更新（系统设置 → 通用 → 软件更新）

触控板手势全解

MacBook 触控板是公认笔记本界天花板——学会手势，鼠标可以退休

所有手势的开关与演示都在 系统设置 → 触控板，分「光标与点按」「滚动缩放」「更多手势」三页，每页都有动态演示视频，强烈建议对着调一遍。以下是最值得练的九个：

手势动作效果（Windows 对照）
轻点点按单指轻点一下单击（默认无需按到底，力度轻柔）
辅助点按（右键）双指轻点 或 右下角角点右键菜单，等同鼠标右键
双指滚动双指上下滑滚动页面（方向注意见下方专题）
智能缩放双指双击放大/还原网页某一栏（无直接 Win 对照）
捏合缩放双指张合图片/网页缩放
调度中心三指（或四指）上滑≈ Win+Tab：摊平所有窗口
切换全屏空间三指左右滑≈ Ctrl+Win+←/→：切虚拟桌面
通知中心双指从触控板右缘向左滑点开屏幕右上角时间，看通知/小组件
启动台拇指与其他三指捏合≈ 开始菜单：一屏展示所有 App

专题：「自然滚动」为什么是"反的"？

用惯 Windows 鼠标滚轮的人初见 Mac 一定懵：双指下滑，页面却向上滚。这不是 bug——macOS 的逻辑是手指在"推纸"：内容像一张纸贴在玻璃下，手指上推，纸就跟着往上走，和 iPhone 完全一致。Windows 触摸屏也是这个逻辑，只是鼠标滚轮时代把大家训练反了。

接受不了？可以关

系统设置 → 触控板 → 滚动缩放 → 关闭「自然滚动」，立刻回到 Windows 手感（但会连带影响鼠标滚轮方向，鱼和熊掌不可兼得）。

建议的姿势

坚持 3~7 天适应它。因为 iPhone / iPad / Mac 触控板全线统一为自然滚动，一旦适应，所有设备无缝切换，长期收益更高。

隐藏神技：三指拖移

默认拖拽文件要按住触控板不放，很累。开启「三指拖移」后，三指轻扫即可拖动窗口/文件，再点一下释放：路径为 系统设置 → 辅助功能 → 指针控制 → 触控板选项 → 拖移样式 → 三指拖移。这是 Mac 老玩家的标配设置。

要不要外接鼠标？完全可以——Mac 对 Windows 键鼠即插即用。但手势熟练后，大多数日常操作触控板更快；写代码、剪视频时再接鼠标不迟。

访达（Finder）与文件系统

把"资源管理器"的肌肉记忆，翻译成 Mac 的文件哲学

访达（Finder）= Mac 的资源管理器，永远待在 Dock 最左端，无法退出。快捷键 Cmd+N 新开访达窗口（对照 Win+E 打开资源管理器）。

新机必做的 4 项访达设置

菜单栏 → 访达 → 设置（旧版叫"偏好设置"）：

  1. 通用：把"新访达窗口显示"改为家目录（默认"最近使用"很反直觉）
  2. 高级：勾选「显示所有文件扩展名」——Windows 用户没有扩展名会疯
  3. 边栏：勾选家目录与常用位置，它们会出现在每个访达窗口左侧
  4. 菜单栏「显示」→ 「显示路径栏」与「显示状态栏」——窗口底部立刻多出面包屑路径与容量信息

Mac 文件系统 vs Windows 的三大观念差

观念WindowsmacOS
文件之家C:\Users\你的名字/Users/你的名字（波浪号 ~），下分桌面/文档/下载/图片/影片/音乐/资源库(Library)
盘符C 盘、D 盘、E 盘…没有盘符！所有磁盘作为"宗卷"挂在 /Volumes 下，桌面上直接显示磁盘图标，即插即用
软件安装位置注册表 + Program Files + AppData 到处散落一个 App = 一个 .app 包（其实是特殊文件夹），删掉即卸载主体

每天都会用的效率操作

  • 快速预览（Quick Look）：选中任意文件按 空格，秒开预览——PDF、图片、视频、Word、代码都能看，再按 空格 关闭。这是 Mac 杀手级功能，没有 Windows 对照物
  • 四种视图：Cmd+1/2/3/4 分别是图标/列表/分栏/画廊视图。分栏视图（Cmd+3）最接近资源管理器的层级导航
  • 标签（Tags）：右键文件 → 选颜色标签。一个文件可以同时属于"工作"+"重要"，点击边栏标签跨文件夹过滤
  • 智能文件夹：存储一个搜索条件（如"所有大于 1GB 的视频"）作为动态文件夹
  • 剪切文件：Mac 没有剪切概念，而是 Cmd+C 复制后，到目标位置按 Cmd+Option+V = 移动
  • 前往文件夹：Cmd+Shift+G 输入路径直达（高级玩家入口）

文件格式速查（Windows 用户重点）

文件系统Windows 读写Mac 读写结论
APFS（Mac 默认）❌ 不识别✅Mac 系统盘专用
NTFS（Windows 默认）✅读取✅ / 写入❌Mac 只能读！写入需第三方驱动（见模块 12）

文件名注意：Mac 允许文件名含 ? * | 等字符，但 Windows 不允许（Windows 只禁止 \ / : * ? " < > |）。如果文件要传回 Windows，提前避开这些字符，否则会传输失败或自动改名。

应用的安装与卸载

告别 .exe 与控制面板——Mac 装软件的四种姿势

四种安装姿势

点 Dock 上的 App Store（蓝底 A 字图标）→ 搜索 → 「获取/安装」，用触控 ID 或 Apple 账户密码确认。和手机装 App 一样，最安全省心，自动更新。日常软件（微信、QQ、WPS、剪映）全都有。

从官网下载 .dmg 文件（相当于虚拟光盘）→ 双击挂载 → 弹出的窗口里把 App 图标拖进 Applications 文件夹 → 完成。用完推出 dmg（右键 → 推出，或把它拖到废纸篓）。

首次打开提示"无法验证开发者"？别慌，这是 Gatekeeper 安全机制在工作。去 系统设置 → 隐私与安全性，底部会出现「仍要打开」按钮；或右键 App → 「打开」也能绕过一次验证。

少数大型软件（Adobe 全家桶、部分驱动）用 .pkg，长得和 Windows 安装器一样：双击 → 一路「继续」→ 输管理员密码。注意看清每一步的选项。

命令行党最爱：brew install --cask xxx 一条命令装好。这是「精通阶段」的内容，详见模块 16。

卸载：拖进废纸篓只完成了 50%

把 App 拖进废纸篓只是删掉了程序本体。macOS 没有 Windows 那种"卸载向导"，App 的配置、缓存、聊天记录、登录状态全部留在 ~/Library（用户资料库）里——重装回来会发现"设置全还在"，就是这个原因。想彻底删干净，接着往下看。

  1. 第一步 · 删本体：App Store 装的 → 启动台长按图标抖动 → 点 ×；其他方式装的 → 「应用程序」文件夹拖进废纸篓
  2. 第二步 · 残留体检：用下面任一方法扫描 ~/Library 里的关联文件（见下方"四种清理姿势"）
  3. 第三步 · 清倒废纸篓：别让"已删除"的 App 在废纸篓里继续躺尸占空间

残留数据都藏在哪？（可搜索）

macOS 用 Bundle ID（形如 com.tencent.xinWeChat）标记每个 App 的数据。访达按 Cmd+Shift+G 输入 ~/Library 即可进入下表这些目录：

藏匿点装的是什么清理优先级
~/Library/Application Support/应用主数据：配置、数据库、聊天记录、下载的素材包。体积大头，一个微信能吃几十 GB🔴 必清
~/Library/Caches/缓存文件，删了会自动重建，最安全🔴 必清
~/Library/Preferences/偏好设置 .plist 文件（按 Bundle ID 命名），存着你的设置和登录状态🔴 必清
~/Library/Containers/沙盒应用（多为 App Store 应用）的全部数据都在这，整个文件夹都是它的🔴 必清
~/Library/Group Containers/应用组共享数据（如同开发商的多个 App 共享的登录态）🟡 建议清
~/Library/LaunchAgents/后台自启服务——流氓软件重灾区！有些 App 删了本体，后台进程还在偷偷自启🔴 必清
~/Library/Saved Application State/窗口位置与恢复状态🟡 建议清
~/Library/Logs/运行日志，排错用的，日常无用🟡 建议清
~/Library/WebKit/ 与 ~/Library/HTTPStorages/Electron 应用（如各类"套壳网页"软件）的网页数据、Local Storage🟡 建议清
~/Library/Cookies/登录 Cookie，删了下次要重新登录🟢 可选
/Library/Application Support/系统级残留（全局安装的驱动、助手类软件），需要管理员密码🟡 谨慎
/Library/LaunchAgents/ 与 /Library/LaunchDaemons/系统级后台服务（注意开头没有 ~），某些驱动/助手软件的服务项🟡 谨慎

😵 没找到，试试"缓存""自启""沙盒"

四种彻底清理姿势

AppCleaner（freemacsoft.net/appcleaner，免费）是 macOS 圈口碑最好的免费卸载工具：把 App 图标拖进它的窗口，它会自动扫描出上面表格里所有关联文件，勾选后一键全删。适合 99% 的场景，新手首选。

同类免费选择：Pearcleaner（开源、国人开发、更现代）。付费的 CleanMyMac 功能更全但非必需。

不想装任何软件？访达手动清理三连：

  1. 按 Cmd+Shift+G 输入 ~/Library 回车
  2. 用右上角搜索框搜 App 名或 Bundle ID（如 xinWeChat），搜索范围选"此文件夹"
  3. 把搜出来的同名文件/文件夹拖进废纸篓（认准路径以 ~/Library 开头再删）

查 Bundle ID 技巧：右键 App → 显示简介 → "种类"下方的"标识符"就是。

终端一行命令找出某 App 的所有残留（以微信为例，把关键词换成别的 App 名即可）：

find ~/Library -iname "*wechat*" 2>/dev/null

确认列表无害后批量删除（先看清楚再删，-delete 不可撤销）：

find ~/Library -iname "*wechat*" -maxdepth 3 -delete 2>/dev/null

清掉它的偏好设置与自启服务：

defaults delete com.tencent.xinWeChat 2>/dev/null
launchctl unload -w ~/Library/LaunchAgents/com.tencent.xinWeChat.plist 2>/dev/null
红线：com.apple.* 前缀的是系统组件，绝对不要删；终端命令详见模块 15，看不懂的命令先别跑。

带内核扩展、虚拟化驱动、后台服务的软件（Adobe 全家桶、Parallels Desktop、VMware、部分声卡驱动），卸不干净会留下系统级驱动。这类软件官网都提供官方卸载器（如 Adobe Creative Cloud Uninstaller），优先用它，删完再用 AppCleaner 扫尾。

  • 注册表残留是顽疾，第三方卸载器是刚需

文件迁移与双系统协同

和旧 PC 说再见（但偶尔还要来往）的完全方案

方案 A：迁移助理完整搬家

  1. PC 端准备：更新 Windows 到最新 → 关闭杀毒软件/防火墙/VPN → 从 Apple 官网下载与 Mac 系统匹配的 Windows 迁移助理（macOS Sonoma/Sequoia/Tahoe 对应 3.0.1.0 版）
  2. 两台电脑连同一 Wi-Fi（或用网线直连更快），彼此靠近、全程插电
  3. Mac 端：首次开机时选「从 Windows PC 传输」；已完成设置则打开「应用程序 → 实用工具 → 迁移助理」→ 选「从 Windows PC」→ 继续
  4. Mac 屏幕出现配对代码，在 PC 的迁移助理中输入 → PC 开始连接
  5. Mac 上勾选要搬的类别（邮件/联系人/日历/浏览器书签/用户文件夹文件/桌面壁纸等）→ 继续，等待完成（100GB 约 1~3 小时，有线更快）
  6. 重启后用新密码登录，邮件、通讯录、日历、书签各就各位
迁移助理搬不了：Windows 上安装的软件本体、系统设置里的非账户类偏好。软件需要重新装 Mac 版——正好趁机断舍离。

方案 B：移动硬盘手动搬运

  • 硬盘格成 exFAT：Windows 上右键磁盘 → 格式化 → exFAT；或 Mac 上用「磁盘工具」抹掉（GUID 分区图 + exFAT）
  • 优先搬：文档 / 桌面 / 图片 / 下载 / 视频 五大目录 + 浏览器书签导出（浏览器自带导出 HTML 功能）+ 微信/QQ 聊天记录（各客户端官方迁移工具）
  • OneDrive 用户直接装 Mac 版客户端登录即同步，最无缝

双机共存：局域网互访（SMB 共享）

  • Mac 访问 Windows 共享：访达 → 菜单「前往 → 连接服务器」（Cmd+K）→ 输入 smb://电脑名或IP → 输 Windows 账号密码

Time Machine 备份

备份是"精通"的第一课——出事那天你会感谢今天的自己

为什么是 Time Machine 而不是手动拷贝

Time Machine 是 macOS 内置的自动增量备份：插上备份盘后每小时自动备份，保留最近 24 小时每小时版本、最近一个月每日版本、再往前的每周版本，空间不足时自动删最旧的。文件误删、误改、系统崩了都能"坐时光机回去"——手动拷贝永远做不到版本级恢复。

三步开启

  1. 备一块不小于 Mac 数据量 2 倍的移动硬盘（SSD 体验最佳）
  2. 插入硬盘 → 系统弹出「用作 Time Machine 备份磁盘？」→ 点「用作备份磁盘」；没弹窗就去 系统设置 → 通用 → Time Machine → 添加备份磁盘
  3. 首次备份全量拷贝（较慢），之后每小时增量、无感运行。想立即手动备份：菜单栏 Time Machine 图标 → 「立即备份」

两种恢复姿势

  • 找回单个文件/旧版本：进入原文件夹 → 菜单栏 Time Machine 图标 → 「进入 Time Machine」→ 时间轴翻历史版本 → 选中「恢复」
  • 整机恢复：Apple Silicon Mac 长按电源键直到出现「载入启动选项」→ 选项 → 从 Time Machine 备份恢复。（Intel Mac 是开机按 Cmd+R 进恢复模式）
Windows 对照
  • 文件历史记录（功能弱、少人用）
  • 系统映像备份（繁琐、半弃用）
  • 实际多数人裸奔
macOS 生态
  • Time Machine 全自动、版本化、随插随用
  • 迁移助理可从备份整机还原到新 Mac
  • 本地快照兜底（没插盘也有近期版本可回滚）
3-2-1 原则提醒：Time Machine 盘插着才有备份，笔记本用户经常忘插。重要数据再加一层：iCloud 云盘 / OneDrive 同步「桌面与文稿」，双保险。备份盘和电脑放不同地方，防丢防盗。

自动化：快捷指令、AppleScript 与定时任务

让 Mac 替你干活——从"一键例程"到"无人值守"

第一站：快捷指令（Shortcuts）——零代码

App Store 自带免费 App「快捷指令」，图形化拖积木拼自动化流程，且与 iPhone/iPad 云端同步。新手第一个可以照抄的例子：「早上好」：

  1. 打开快捷指令 → + 新建 → 命名"早上好"
  2. 添加动作：「获取天气」→「显示结果」；「打开 App」选日历；「设定播放音量」30%
  3. 点顶部 ⓘ → 「固定到菜单栏」（或添加到程序坞）——以后菜单栏一点全跑
  4. 进阶：在「自动化」标签里设触发条件：特定时间 / 连接某 Wi-Fi / 关闭某 App 时自动执行

常用玩法：批量压缩图片、截图转 PDF、按文件夹整理下载、定时提醒喝水、连上公司 Wi-Fi 自动开焦点模式。macOS Tahoe 起快捷指令还支持从网页导入他人分享的现成指令，聚焦搜索也能直接搜到并运行。

第二站：AppleScript——发号施令的英语

AppleScript 是 Mac 独有的自然语言风格脚本，能让"支持它"的应用执行操作。打开「脚本编辑器」试第一条：

tell application "Finder"
  display dialog "你好，Mac！" buttons {"继续", "算了"} default button "继续"
end tell

点运行 ——访达弹出一个对话框。这套 tell application ... end tell 语法能控制访达、Safari、邮件、音乐等大多数原生 App：批量改文件名、自动群发邮件、定时导出报表都有人用 AppleScript 做。查每个 App 支持哪些命令：脚本编辑器 → 文件 → 打开词典。

第三站：launchd——无人值守定时任务

对照 Windows「任务计划程序」。macOS 用 launchd + plist 配置文件管理定时/开机任务。新手不用手写 plist，用社区封装好的 LaunchControl（GUI 付费）或 Homebrew 装 brew install launchd 周边工具；也可以先用「快捷指令自动化」的时间触发器顶替大多数场景。

安全、隐私与性能维护

最后一课：让这台 Mac 又快又稳又安全地跑十年

安全五件套（macOS 的隐形保镖）

机制干什么你要做的
FileVault全盘加密，电脑丢了数据也读不出系统设置 → 隐私与安全性 → FileVault → 打开（开启后务必保管好恢复密钥）
Gatekeeper拦截未签名/未公证的应用与恶意软件保持「App Store 与已知开发者」；来路不明的 App 想清楚再「仍要打开」
XProtect内置恶意软件特征库，静默后台扫描什么都不用做，随系统更新自动升级
SIP 系统完整性保护锁死系统目录，连 root 都改不了永远不要关闭。网上教程让你关 SIP 的，九成九是坑
防火墙挡入站连接系统设置 → 网络 → 防火墙 → 打开（家用笔记本可选，公共网络建议开）

隐私权限：App 申请时多看一眼

系统设置 → 隐私与安全性 → 各权限分类（相机/麦克风/屏幕录制/完全磁盘访问…）：App 首次要动这些能力必须弹窗问你，随时可在此处收回。这与 Windows 的权限模型类似但粒度更细。给 App 开「完全磁盘访问」前想清楚它是否真的需要。

性能：活动监视器 = 任务管理器

  • 打开：聚焦搜「活动监视器」，或 Cmd+Option+Esc 强退窗口里的按钮直达
  • CPU 页签找失控进程；能耗页签看谁在吃电池（"能耗影响"高的 App 拉黑）
  • 内存页签重点看底部「内存压力」图：绿色=健康，黄色=吃紧，红色=才需要关 App。Mac 的"已用内存"高是正常缓存策略，不要拿 Windows 的"空闲内存越多越好"观念来看——macOS 会把不活跃内存压缩复用
  • 风扇狂转/掉电快：先查「能耗」页签和「登录项」（系统设置 → 通用 → 登录项与扩展），再考虑其他

维护四习惯（就这四条，别装管家）

  1. 存储留 15%：系统设置 → 通用 → 储存空间，可视化清理建议；SSD 长期满盘会显著降速减寿
  2. 保持系统更新：软件更新不仅有新功能，XProtect 特征库和安全补丁也走这里
  3. 每季度清缓存：浏览器缓存、~/Library/Caches 手动删、brew cleanup；仅此而已
  4. 电池健康：系统设置 → 电池 → 打开「优化充电」；长期插电使用的，M 系芯片管理已很好，无需焦虑
Windows 老习惯（可丢弃）
  • 装杀毒全家桶（Mac 有 XProtect 兜底）
  • 清内存软件（macOS 自动压缩调度）
  • 磁盘碎片整理（SSD 无此概念，且系统盘 APFS 自动优化）
  • 重装系统保平安（Mac 出问题先试安全模式/恢复模式修复）
Mac 时代好习惯
  • 出怪事先重启（90% 的玄学问题终结者）
  • 更新前看一眼兼容性（尤其是主力生产力工具）
  • 备份盘常插，Time Machine 常开
  • 系统卡顿查「登录项」而非重装

急救小抄：出事了怎么办

App 卡死了怎么办？
先 Cmd+Option+Esc 打开强制退出窗口（相当于 Ctrl+Alt+Del 的应用列表），选中无响应 App → 「强制退出」。个别 App 菜单里也有「退出并重新打开」。
系统卡到鼠标都动不了？
长按电源键 10 秒强制关机再开机（数据丢失风险仅限未保存内容）。重启后若仍卡，开机时长按电源键进入「载入启动选项」→ 选「选项」→ 用「磁盘工具」的「急救」修复宗卷。
系统越用越慢？
按顺序排查：① 活动监视器能耗/CPU 页签找元凶 → ② 系统设置 → 登录项，砍掉开机自启 → ③ 储存空间是否低于 15% → ④ 重置 SMC/NVRAM（Intel 机型适用；Apple Silicon 无此操作，重启即可）→ ⑤ 最后一招：迁移助理备份后重装系统。

macOS 有 XProtect 内置恶意软件防护 + Gatekeeper 应用验证，对普通用户（只从 App Store/官网装软件）足够安全，无需第三方杀软。真正的风险是"自己同意安装"的流氓软件和钓鱼，这层任何杀软都防不了你的手。参考：Apple 平台安全指南。
内存 8GB 够用吗？为什么活动监视器里内存快满了？
macOS 有内存压缩与统一内存架构，"已用内存"高是正常缓存策略，看「内存压力」颜色判断：绿色就健康。日常办公 8GB 可用，重度的视频剪辑/虚拟机/大型工程建议 16GB 起——买前按三年后的需求定配置。
为什么关了窗口软件还在运行？
macOS 设计哲学：关窗口≠退应用（很多 App 无窗口也能后台干活，如音乐播放）。看程序坞图标下方的小点判断是否在运行，Cmd+Q 才是真退出。不习惯可以关窗口后顺手 Cmd+Q。
Mac 能打游戏吗？
原生大作库确实远小于 Windows。可行路径：App Store 的 Apple Arcade、原生移植大作（近年《生化危机》《刺客信条》系列有原生版）、CrossOver/Whisky 转译层跑 Windows 游戏（M 系列芯片兼容性持续改善）、云游戏（GeForce NOW）。重度 PC 玩家建议保留一台 Windows 机。
外接 Windows 键盘能用吗？Win 键当什么用？
即插即用。系统设置 → 键盘 → 「修饰键」可把 Win(⌘) 与 Alt(⌥) 功能互换，让 Ctrl+C 的肌肉记忆直接生效。注意外接键盘的 Win→Command 位置恰好在拇指位，比标准 Mac 布局更顺手。
我的 NTFS 移动硬盘为什么在 Mac 上只能读？
macOS 原生只支持 NTFS 读取。方案见模块 12：格成 exFAT（免费但要重格）/ 买 Paragon NTFS 驱动 / 实验性开源方案。重要数据优先选前两个。
Windows 上的软件在 Mac 上有替代品吗？
Office/Adobe/主流国产软件（微信/QQ/钉钉/百度网盘）都有官方 Mac 版。专业软件（Visio、Project）无 Mac 版，可用网页版或 Lucidchart/Merlin 替代；行业刚需 Windows 软件的，可用 Parallels Desktop 装 ARM 版 Windows（M 芯片可跑 x86 转译）。
Mac 需要定期重启吗？碎片整理呢？
不需要刻意定期重启，系统更新或出玄学问题时重启即可。SSD 无碎片整理概念，APFS 文件系统自动优化——磁盘工具里的"急救"都不用常跑。
触控板那么好，还要买鼠标吗？
文字工作/浏览：不需要，手势效率更高。精准拖拽场景（设计、剪辑、Excel 大表、游戏）：建议入一个。蓝牙鼠标即插即用，罗技等驱动也有 Mac 版。
App 打不开，提示"已损坏"或"无法验证开发者"怎么办？
提示"无法验证"：系统设置 → 隐私与安全性 → 底部「仍要打开」，或右键 App → 打开。提示"已损坏"：多为下载不完整或 Gatekeeper 隔离属性误报——重新从官网下载；国内网络下载的安装包易出现此问题。仍然打不开就别硬开，换个来源。
程序坞越来越乱怎么整理？
拖出程序坞即移除（应用本体不动，只是移出 Dock）；把相关 App 拖到一起会自动生成分隔；或建一个「应用文件夹」拖进程序坞归类。原则：程序坞只放每天用的 8~10 个，其余交给聚焦搜索。
买了新 Mac，旧 Mac 的数据怎么搬？
Mac→Mac 最简单：新机首次设置时选「从 Mac、Time Machine 备份或启动磁盘传输」，或用雷电线直连两台机器跑迁移助理，几十 GB 也就半小时级别。详见模块 14 的 Time Machine 与 Apple 迁移助理官方文档。

通关路线图 · 90 天计划

不用一天肝完。按这个节奏走，三个月后你就是别人眼里"很懂 Mac 的那个人"。

第 1 周 · 生存期（模块 1-6）

完成首次设置与数据迁移；对照本教程把系统设置、访达设置调一遍；每天强迫自己用触控板手势，不开鼠标；把 10 个最常用快捷键（模块 11 表格前 10 行）练成肌肉记忆。检验标准：不看教程独立装/卸一个 App，用三指上滑切桌面。

第 1 个月 · 效率期（模块 7-12）

抛弃"开始菜单"改用聚焦；学会分屏与调度中心的工作流；把快捷键对照表打印/收藏，遇到要按 Ctrl 的场合先想 Cmd；搞定 NTFS 硬盘方案，彻底告别双机搬运的痛。检验标准：一天下来没碰过鼠标右下角找东西，效率不低于 Windows 时期。

第 2-3 个月 · 精通期（模块 13-18）

配齐 Time Machine 备份；装 Homebrew 并用它管理所有软件更新；用快捷指令把一件每周重复做的事自动化；打开终端完成一次文件批量重命名。检验标准：遇到问题第一反应是"聚焦搜一下/查手册"，而不是"下个管家"。

毕业之后 · 持续进化

关注每年 6 月 WWDC 的 macOS 新版本功能介绍（apple.com.cn 的 macOS 页面会同步更新）；想深入开发再学 Xcode/Swift；把你的快捷指令分享给朋友。Windows 的肌肉记忆不会白学——如今你两套都会，才是真正的双修玩家。
