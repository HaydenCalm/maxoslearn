# maxoslearn · MacBook 从 0 到 1 到精通完全教程

> 二次元霓虹赛博风格 · 从 Windows 过渡到 macOS · 18 模块三阶段

## 在线访问

打开 https://HaydenCalm.github.io/macosLearn/ 即可学习。

## 教程内容

| 阶段 | 模块 |
|---|---|
| 🌱 新手村（1-6） | 开箱初始化 → 桌面程序坞 → 触控板手势 → 访达文件管理 → 应用安装卸载 → 系统设置 |
| ⚡ 进阶（7-12） | 键盘输入法 → 多任务调度中心 → Spotlight → 截图录屏 → Win/Mac 快捷键对照 → Windows 文件迁移 |
| 🔥 精通（13-18） | Apple 生态连续互通 → Time Machine 备份 → 终端入门 → Homebrew 包管理 → 自动化 → 安全性能维护 |

另有「实战训练场」：快捷键肌肉记忆训练器 + 三阶段 Boss 战测验 + XP 等级 + 徽章墙。

## 主题

- 🌙 夜晚模式（默认）：霓虹赛博深墨蓝
- ☀️ 白天模式：暖色系二次元（导航栏切换按钮）

## 技术栈

纯前端单页应用，无后端依赖：
- 手写 CSS（霓虹赛博 / 暖色二次元双主题系统）
- AOS 滚动动画
- Font Awesome 图标
- Google Fonts（ZCOOL KuaiLe + Noto Sans SC）
- canvas-confetti 撒花动画
- localStorage 进度持久化
